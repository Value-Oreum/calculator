# 오름 수익계산기 (OREUM Profit Calculator)

회사가 소싱하는 제품별 납품 체계와 중간 유통 수익 배분 차이를 반영한 수익 계산기입니다.
메인 화면에서 **제품 종류를 선택**하면 해당 제품 전용 계산 UI가 열립니다.

> 단일 파일(`index.html`) 정적 웹앱입니다. 별도 빌드/설치 없이 브라우저로 바로 열어 사용합니다.

## 제품별 계산 로직

### 💡 LED
1. **발주액 입력** — 멀티미디어 자재비 + 공사비(인테리어비) = 전체 발주액
2. **수익 옵션** (발주액 기준 / 자재비 기준) → 공사비 초과분 추가 수익 반영 → **최종 수익 합계**
3. **에이전시 제공 수수료** — 10% ~ 40% 슬라이더(1% 단위)
   `순수익(NET) = 최종 수익 합계 − (발주액 × 에이전시 수수료율)`
4. **법인세(영업비 포함)** — 12% 또는 22% 선택
   `오름 최종 REAL 수익 = 순수익(NET) − 순수익(NET) × 법인세율`

### 🤖 AI ROBOT
1. **발주 대수** 직접 입력 · 1대당 가격 **20,000,000원 (VAT 별도)** 고정
   `발주금액 = 발주대수 × 20,000,000`
2. **오름 수익률** — 35 / 40 / 45 / 50 / 55% + 직접입력
   `최초 수익금액(오름 수수료) = 발주금액 × 수익률`
3. **VIP 수수료 빽업 필요 여부** 선택
   - **필요 (4-1)**
     - `VIP 수수료 = 발주금액 × 입력 수수료율`
     - `실제 매입비용 = (오름 수수료 − VIP 수수료) ÷ 0.75` *(25% 안전 매입)*
     - `법인세(영업비 포함) = (최초 수익금액 − 실제 매입비용) × 12% 또는 22%`
     - `오름 최종 REAL 수익 = 최초 수익금액 − 실제 매입비용 − 법인세`
   - **필요 없음 (4-2)**
     - 영업에이전시 수수료 10% ~ 40% 슬라이더 → `에이전시 수수료 = 발주금액 × 수수료율`
     - `법인세(영업비 포함) = (최초 수익금액 − 에이전시 수수료) × 12% 또는 22%`
     - `오름 최종 REAL 수익 = 최초 수익금액 − 에이전시 수수료 − 법인세`
